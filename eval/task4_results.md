# Task 4 — Hybrid Retrieval and Reranking

## Implementation

We implemented four retrieval modes:

- BM25 keyword search
- Vector similarity search using OpenAI embeddings
- Hybrid retrieval using Reciprocal Rank Fusion (RRF)
- Hybrid retrieval with local Cross-Encoder reranking

The reranking pipeline combines the top 20 BM25 and top 20 vector candidates, removes duplicates, and reranks the resulting passages using `cross-encoder/ms-marco-MiniLM-L6-v2`.

We also added in-memory search index caching and source-prefix metadata filtering.

## Preliminary Results

Evaluation on 10 development questions using question-level Hit@5:

| Method | Hits | Hit@5 |
|---|---|---|
| BM25 | 5/10 | 50% |
| Vector | 6/10 | 60% |
| Hybrid RRF | 8/10 | 80% |
| Hybrid + Cross-Encoder | 8/10 | 80% |

Hybrid retrieval performed better than either individual retrieval method on this small development set.

The reranker improved Q006 from a miss to a hit but changed Q001 from a hit to a miss, leaving the overall score unchanged.

These are exploratory development results, not final evaluation results. Some gold labels were expanded after inspecting retrieval results.

## Testing

- Index cache reuse confirmed.
- Cross-Encoder loading and reranking confirmed.
- Source-prefix filtering tested.
- Streamlit retrieval and answer generation tested.
- Five evidence passages displayed successfully.

## Known Limitations

- Citation IDs generated by OpenAI are not yet strictly validated.
- Reranking has not demonstrated an overall Hit@5 improvement on the current development set.
- Larger, independently annotated evaluation and latency measurements are still needed.

Citation validation and answer-quality improvements will be addressed in Task 5.
